JavaScript Arrays

A comprehensive guide to array methods, iteration, transformation, and modern array patterns in JavaScript.

Arrays are one of the most fundamental data structures in JavaScript, allowing you to store and manipulate ordered collections of data. Mastering array methods is crucial for writing efficient, clean, and powerful code.

1. Creating Arrays

There are several ways to create arrays in JavaScript, with the array literal being the most common and preferred method.

// 1. Array literal (most common and simple)
const fruits = ["apple", "banana", "cherry"];
const mixed = [1, "hello", true, { name: "Alice" }];

// 2. Array.from() - Creates an array from an array-like or iterable object.
const fromString = Array.from("hello"); // ["h", "e", "l", "l", "o"]
const fromSet = Array.from(new Set([1, 2, 2, 3])); // [1, 2, 3]
const fromLength = Array.from({ length: 3 }, (_, i) => `Item ${i + 1}`); // ["Item 1", "Item 2", "Item 3"]

// 3. Spread syntax (...) - Useful for creating a shallow copy or combining arrays.
const fruitsCopy = [...fruits];
const moreFruits = ["date", "elderberry"];
const combined = [...fruits, ...moreFruits];
Note: Avoid using the new Array() constructor. It has inconsistent behavior (new Array(5) creates an empty array of length 5, while new Array(1, 2) creates the array [1, 2]). Use array literals or Array.from() instead.

2. Accessing & Modifying Elements

You can access array elements using their zero-based index. Many methods modify the array in-place (mutating methods), while others return a new array (immutable methods).

const fruits = ["apple", "banana", "cherry"];

// Access by index
console.log(fruits[0]);     // "apple"
console.log(fruits.at(-1)); // "cherry" (ES2022 feature for accessing from the end)

// Modify an element
fruits[1] = "blueberry"; // fruits is now ["apple", "blueberry", "cherry"]

// --- Mutating Methods ---

// Add elements
fruits.push("date");        // Adds to the end
fruits.unshift("avocado");  // Adds to the beginning (can be slow on large arrays)

// Remove elements
const last = fruits.pop();  // Removes from the end
const first = fruits.shift(); // Removes from the beginning (can be slow on large arrays)

// splice() - The swiss army knife for adding/removing elements at any position
const months = ['Jan', 'March', 'April', 'June'];
months.splice(1, 0, 'Feb'); // Inserts at index 1: ["Jan", "Feb", "March", "April", "June"]
months.splice(4, 1, 'May'); // Replaces 1 element at index 4: ["Jan", "Feb", "March", "April", "May"]

3. Iteration Methods

These are some of the most powerful and commonly used array methods. They allow you to iterate over an array and perform transformations, filtering, and aggregations without needing a manual for loop.

const numbers = [1, 2, 3, 4, 5];

// forEach() - Executes a function for each element. Does not return a value.
numbers.forEach((num, index) => {
    console.log(`Element at index ${index} is ${num}`);
});

// map() - Creates a new array by transforming every element.
const doubled = numbers.map(n => n * 2); // [2, 4, 6, 8, 10]

// filter() - Creates a new array with only the elements that pass a test.
const evens = numbers.filter(n => n % 2 === 0); // [2, 4]

// find() - Returns the first element that passes a test.
const found = numbers.find(n => n > 3); // 4

// reduce() - Accumulates the array into a single value.
const sum = numbers.reduce((accumulator, current) => accumulator + current, 0); // 15
const max = numbers.reduce((a, b) => Math.max(a, b)); // 5
Best Practice: Prefer using immutable iteration methods like map, filter, and reduce over manual for loops. They are more declarative, less error-prone, and can be chained together for expressive data transformations.

4. Searching & Sorting

Methods for finding elements or reordering the array.

const arr = [3, 1, 4, 1, 5, 9, 2, 6];

// includes() - Check if an element exists. Returns true or false.
console.log(arr.includes(5));    // true

// indexOf() / lastIndexOf() - Find the index of an element. Returns -1 if not found.
console.log(arr.indexOf(1));     // 1 (first occurrence)
console.log(arr.lastIndexOf(1)); // 3 (last occurrence)

// sort() - Sorts the array in-place (mutates the original array!).
// Always provide a compare function for numbers.
const sorted = [...arr].sort((a, b) => a - b); // Use spread to create a copy first
// sorted is [1, 1, 2, 3, 4, 5, 6, 9]

// Sorting an array of objects
const people = [
    { name: "Alice", age: 30 },
    { name: "Bob", age: 25 },
];
people.sort((a, b) => a.age - b.age); // Sorts by age, ascending

// reverse() - Reverses the array in-place (mutates!).
const reversed = [...arr].reverse(); // Create a copy first

5. Creating New Arrays from Existing Ones

These methods allow you to transform or combine arrays without modifying the originals.

const numbers = [1, 2, 3, 4, 5];

// slice() - Extracts a portion of an array into a new array.
const sliced = numbers.slice(1, 4); // [2, 3, 4] (from index 1 up to, but not including, index 4)
const copy = numbers.slice();       // Creates a shallow copy of the entire array.

// concat() - Merges two or more arrays.
const moreNumbers = [6, 7];
const combined = numbers.concat(moreNumbers); // [1, 2, 3, 4, 5, 6, 7]
// The spread syntax is often preferred for this:
const combinedSpread = [...numbers, ...moreNumbers];

// flat() - Creates a new array with all sub-array elements concatenated into it.
const nested = [1, [2, 3], [4, [5]]];
console.log(nested.flat());    // [1, 2, 3, 4, [5]] (flattens one level)
console.log(nested.flat(2));   // [1, 2, 3, 4, 5] (flattens two levels)

// flatMap() - A combination of map() and flat() in one step.
const sentences = ["hello world", "how are you"];
const words = sentences.flatMap(sentence => sentence.split(" ")); // ["hello", "world", "how", "are", "you"]

6. Array Destructuring (ES6)

A powerful and concise way to extract values from an array into distinct variables.

const arr = [1, 2, 3, 4, 5];

// Basic destructuring
const [first, second] = arr; // first = 1, second = 2

// Skip elements with a comma
const [a, , c] = arr; // a = 1, c = 3

// Capture the rest of the array with the rest operator (...)
const [head, ...tail] = arr; // head = 1, tail = [2, 3, 4, 5]

// Swapping variables easily
let p = 1, q = 2;
[p, q] = [q, p]; // p is now 2, q is now 1

7. Advanced Patterns & Best Practices

  • Prefer immutable methods: Methods like map, filter, and slice that return new arrays are safer and lead to more predictable code than mutating methods like sort, splice, or reverse.
  • Use const for arrays: This prevents you from accidentally reassigning the variable to a completely new array, though it doesn't prevent you from modifying the array's contents.
  • Chain methods for readability: Chaining methods like filter and map can make complex data transformations very expressive.
  • Use Set for unique values: The most efficient way to get unique values from an array is to convert it to a Set and back.
// Remove duplicates from an array
const duplicates = [1, 2, 2, 3, 3, 3, 4];
const unique = [...new Set(duplicates)]; // [1, 2, 3, 4]

// Grouping an array of objects by a property
const items = [
    { category: "fruit", name: "apple" },
    { category: "fruit", name: "banana" },
    { category: "veggie", name: "carrot" }
];
const grouped = items.reduce((acc, item) => {
    const key = item.category;
    (acc[key] = acc[key] || []).push(item);
    return acc;
}, {});
/* grouped is:
{
  fruit: [ { category: 'fruit', name: 'apple' }, { category: 'fruit', name: 'banana' } ],
  veggie: [ { category: 'veggie', name: 'carrot' } ]
}
*/
