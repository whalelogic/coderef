Python Functions

A guide to defining and using functions, understanding arguments, and leveraging advanced features like lambdas and decorators.

Functions are a fundamental building block in Python. They are reusable blocks of code that perform a specific task. Defining functions allows you to organize your code, make it more readable, and avoid repetition.

1. Defining and Calling a Function

You define a function using the def keyword, followed by a function name, a set of parentheses for arguments, and a colon. The code block within the function is indented.

# A simple function definition
def greet(name):
    """This is a docstring. It explains what the function does."""
    print(f"Hello, {name}!")

# Calling the function
greet("Alice")  # Output: Hello, Alice!

Return Values

Functions can return a value using the return keyword. If a function does not have a return statement, it implicitly returns None.

def add(a, b):
    """Returns the sum of two numbers."""
    return a + b

result = add(5, 3)
print(f"The result is: {result}") # Output: The result is: 8

# A function can return multiple values (as a tuple)
def get_user_info():
    return "Alice", 30, "alice@example.com"

name, age, email = get_user_info()
print(f"Name: {name}, Age: {age}")

2. Function Arguments

Python offers a flexible way to handle function arguments.

Positional and Keyword Arguments

Arguments can be passed by position or by name (keyword).

def describe_pet(animal_type, pet_name):
    """Displays information about a pet."""
    print(f"I have a {animal_type} named {pet_name}.")

# Positional arguments (order matters)
describe_pet("hamster", "Harry")

# Keyword arguments (order doesn't matter)
describe_pet(pet_name="Willie", animal_type="dog")

Default Arguments

You can provide a default value for an argument. Arguments with default values must come after any arguments without default values.

def describe_pet(pet_name, animal_type="dog"):
    """Displays information about a pet with a default animal type."""
    print(f"I have a {animal_type} named {pet_name}.")

describe_pet("Willie") # Uses the default animal_type
describe_pet("Fluffy", "cat") # Overrides the default

Arbitrary Arguments: *args and **kwargs

*args allows you to pass a variable number of positional arguments, which are collected into a tuple. **kwargs allows you to pass a variable number of keyword arguments, which are collected into a dictionary.

def make_pizza(size, *toppings):
    """Summarizes the pizza being ordered."""
    print(f"\nMaking a {size}-inch pizza with the following toppings:")
    for topping in toppings:
        print(f"- {topping}")

make_pizza(12, "mushrooms", "green peppers", "extra cheese")

def build_profile(first, last, **user_info):
    """Builds a dictionary containing everything we know about a user."""
    user_info['first_name'] = first
    user_info['last_name'] = last
    return user_info

user_profile = build_profile('albert', 'einstein',
                             location='princeton',
                             field='physics')
print(user_profile)

3. Lambda Functions

A lambda function is a small, anonymous function defined with the lambda keyword. It can take any number of arguments but can only have one expression. They are often used for short, throwaway functions.

# A lambda function that adds two numbers
add = lambda x, y: x + y
print(add(5, 3)) # 8

# Lambdas are commonly used with higher-order functions like map() and filter()
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x**2, numbers))
print(squared) # [1, 4, 9, 16, 25]

evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens) # [2, 4]
Best Practice: Lambdas are great for simple, one-line functions. If your logic is more complex, it's better to define a regular function with def for readability.

4. Type Hinting (Python 3.5+)

Type hints allow you to indicate the expected types for function arguments and return values. They do not enforce types but are extremely useful for static analysis tools, IDEs, and code readability.

def greet(name: str) -> None:
    """Greets a person by name."""
    print(f"Hello, {name}")

def add(a: int, b: int) -> int:
    """Adds two integers and returns the result."""
    return a + b

# Type hints improve clarity and allow tools to catch potential errors
greet("Alice")
# greet(123) # A static type checker would flag this as an error

5. Docstrings

A docstring is a string literal that occurs as the first statement in a module, function, class, or method definition. It is used to document what the code does.

def calculate_average(numbers: list[float]) -> float:
    """Calculates the average of a list of numbers.

    Args:
        numbers: A list of floating-point numbers.

    Returns:
        The average of the numbers. Returns 0 if the list is empty.
    """
    if not numbers:
        return 0.0
    return sum(numbers) / len(numbers)

# You can access the docstring using the __doc__ attribute
print(calculate_average.__doc__)
