Ruby Blocks, Procs, and Lambdas

A guide to one of Ruby's most powerful features for creating flexible and expressive code.

Blocks are one of the most distinctive features of Ruby. They allow you to pass a chunk of code to a method to be executed at a later time. Procs and Lambdas are objects that encapsulate these blocks, allowing them to be stored in variables and passed around.

1. The `yield` Keyword

The simplest way to work with a block is by using the yield keyword. A method that contains yield can be called with a block, and the yield keyword will transfer control to the block.

def my_method
  puts "--- Top of method ---"
  yield # Control is passed to the block
  puts "--- Bottom of method ---"
end

my_method do
  puts ">>> Inside the block! <<<"
end

# Output:
# --- Top of method ---
# >>> Inside the block! <<<
# --- Bottom of method ---

You can also pass arguments to yield, which will be passed to the block's parameters.

def greet
  yield "Alice"
  yield "Bob"
end

greet { |name| puts "Hello, #{name}!" }

# Output:
# Hello, Alice!
# Hello, Bob!

2. Blocks

A block is a piece of code that can be passed to a method. It is not an object itself. Blocks are enclosed in either a do...end statement or curly braces {}. By convention, curly braces are used for single-line blocks, and do...end is used for multi-line blocks.

# Multi-line block using do...end
[1, 2, 3].each do |number|
  puts "The number is #{number}"
end

# Single-line block using curly braces
[1, 2, 3].map { |number| number * 2 } #=> [2, 4, 6]

# You can check if a block was passed with `block_given?`
def optional_block
  if block_given?
    yield
  else
    puts "No block was provided."
  end
end

optional_block { puts "A block was given." } #=> A block was given.
optional_block #=> No block was provided.

3. Procs

A Proc (procedure) is an object that encapsulates a block of code. Unlike blocks, Procs are objects, so they can be stored in variables, passed to other methods, and called whenever you like.

# Creating a Proc
my_proc = Proc.new { |name| puts "Hello, #{name}!" }

# Calling a Proc
my_proc.call("World") #=> Hello, World!
my_proc.("World")     # Shorthand syntax
my_proc["World"]      # Another shorthand

# You can pass a Proc to a method that expects a block by using the `&` operator.
def run_a_block(&block)
  puts "About to run the block..."
  block.call
end

my_proc = Proc.new { puts "This is from a Proc!" }
run_a_block(&my_proc)

4. Lambdas

A lambda is a special kind of Proc object. It has a few key differences from a regular Proc, making it behave more like a traditional method.

# Creating a lambda with the lambda keyword
my_lambda = lambda { |x, y| x + y }

# Using the "stabby lambda" syntax (preferred)
my_other_lambda = ->(x, y) { x + y }

puts my_lambda.call(3, 4) #=> 7
puts my_other_lambda.call(5, 6) #=> 11

5. Proc vs. Lambda: Key Differences

There are two main differences between Procs and Lambdas that are crucial to understand.

a) Argument Checking

Lambdas are strict about the number of arguments they receive, just like methods. Procs are flexible and will assign nil to any missing arguments.

# A lambda will raise an ArgumentError if called with the wrong number of arguments.
my_lambda = ->(name, age) { "Name: #{name}, Age: #{age}" }
# my_lambda.call("Alice") #=> ArgumentError: wrong number of arguments (given 1, expected 2)

# A Proc will simply assign nil to missing arguments.
my_proc = Proc.new { |name, age| "Name: #{name}, Age: #{age}" }
puts my_proc.call("Alice") #=> "Name: Alice, Age: " (age is nil)

b) Return Behavior

A return statement inside a lambda returns from the lambda itself. A return statement inside a Proc returns from the method where the Proc was called.

def method_with_lambda
  my_lambda = -> { return "Returned from the lambda" }
  my_lambda.call
  return "Returned from the method" # This line is reached
end

def method_with_proc
  my_proc = Proc.new { return "Returned from the proc" }
  my_proc.call
  return "Returned from the method" # This line is never reached
end

puts method_with_lambda #=> "Returned from the method"
puts method_with_proc   #=> "Returned from the proc"
Key Insight: Use a lambda when you want something that behaves like a method (strict argument checking, local return). Use a Proc when you want more flexibility with arguments or need to return from the enclosing method.

6. Common Enumerable Methods with Blocks

Blocks are most frequently used with Ruby's powerful Enumerable methods to iterate over collections.

# .map (or .collect) - Transforms each element and returns a new array.
numbers = [1, 2, 3, 4]
squares = numbers.map { |n| n * n } #=> [1, 4, 9, 16]

# .select (or .filter) - Returns a new array containing only elements that pass a test.
evens = numbers.select { |n| n.even? } #=> [2, 4]

# .reduce (or .inject) - Accumulates all elements into a single value.
sum = numbers.reduce(0) { |accumulator, current_number| accumulator + current_number } #=> 10
